# 1. ERRONKA: Proiektuaren dokumentazioa

Proiektu honen helburua streaming plataforma baten inguruko webgune
estatikoa sortzea eta beharrezko azpiegitura prestatzea da.

Atal honetan egindako lana, erabilitako prozedurak, konfigurazioak
eta lortutako emaitzak dokumentatuko ditugu.

## Dokumentazioaren atalak

### Sareak

- OSI ereduko lehen bi mailen erabilpena.
- Sare-kableen prestaketa eta konexioa patch panelera eta switchera.
- Pasahitz baten ASCII bihurketa.
- CRC-6-GSM kalkulua eta gehikuntza.
- Modulazioaren eta Manchester kodifikazioaren marrazkiak.
- Webgunearen probak hari gabeko gailu batetik.

[Sareetako dokumentazioa ikusi]({{ '/doc/Sareak.html' | relative_url }})

### Digitalizazioa

- IT eta OT kontzeptuak.
- Teknologia habilitatzaile digitalak (THD).
- Cloud kontzeptua eta proiektuan duen erabilera.

[Digitalizazioko dokumentazioa ikusi]({{ '/doc/Digitalizazioa.html' | relative_url }})

### Datu-baseak

- Streaming plataforma baten beharren azterketa.
- Entitate-erlazio diagrama.
- Eredu erlazional normalizatua eta taulak.
- Erabiltzaileen, rolen, planen eta suskripzioen kudeaketa.
- Edukien eta bistaratzeen kudeaketa.
- Saioa hastean aukeratutako rolarekin bistaratzeak lotzea.
- Datu-basearen inplementazioa ofimatika suite batean.

[Datu-baseetako dokumentazioa ikusi]({{ '/doc/Datu%20Baseak.html' | relative_url }})

### Sistema eragileak

- Windows Server zerbitzariaren prestaketa.
- Web-zerbitzari integratuaren konfigurazioa.
- Webgunearen argitalpena zerbitzarian.
- Beharrezko bolumenak eta RAID konfigurazioa.
- Segurtasun-politikaren ezarpena.

[Sistema eragileetako dokumentazioa ikusi]({{ '/doc/Sistema%20Eragileak.html' | relative_url }})

## Planifikazioa eta jarraipena

Hasierako planifikazioa paperean jasoko da, eta ondoren digitalizatuko da.

Zereginen banaketa, egoera eta proiektuaren jarraipena GitHub Projects
bidez kudeatuko dira.
