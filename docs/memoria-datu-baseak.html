Datu-Basearen Diseinua eta Normalizazioa - Memoria Teknikoa

Streaming plataformaren datu-base erlazionalaren azterketa eta inplementazioa.

Deskargatu .md Aurkibidea

1. Streaming Plataformaren Eskakizunak

Ikus-entzunezkoen plataforma batek behar hauek asetzen ditu:

  • Bezero bakoitzak kontu nagusi bat du (Accounts).
  • Kontuaren barruan profil pertsonalizatu anitzak egon daitezke (Profiles), haur-kontrola barne (Is_Kids).
  • Harpidetza-plan desberdinak (Plans) eta harpidetzak (Subscriptions).
  • Katalogoak filmak eta serieak ditu (Titles) eta hauen atalak (Episodes).
  • Genero anitzak esleitzen dira N:M erlazioarekin (Title_Genres).
  • Ikustaldi bakoitzaren aurrerapena gordetzen da (Watch_History).

2. Bi E-R Proposamenak

1. Proposamena: Baztertua

USERS, USER_ROLES, ROLES, PLANS, SUBSCRIPTIONS, CONTENT, VIEWS.

Muga: ez zuen baimentzen kontu batek hainbat ikusle-profil independente izatea, eta filmak/atalak ezin ziren ondo bereizi.

2. Proposamena: Hautatua

Accounts, Profiles, Plans, Subscriptions, Titles, Episodes, Genres, Title_Genres, Watch_History.

Abantailak: kontuak eta profilak ondo banatuta daude, eta ikustaldi bakoitzaren denbora erregistratzen du.

3. Eredu Erlazionala eta 3NF Normalizazioa

TaulaEremuak
AccountsPK Account_ID, Email, Password_Hash, Country, Created_At
ProfilesPK Profile_ID, FK Account_ID, Name, Is_Kids
PlansPK Plan_ID, Name, Monthly_Price, Max_Screens, Video_Quality
SubscriptionsPK Subscription_ID, FK Account_ID, Plan_ID, Start_Date, End_Date, Status
TitlesPK Title_ID, Name, Type, Release_Year, Age_Rating
EpisodesPK Episode_ID, FK Title_ID, Season, Ep_Number, Duration_Min
GenresPK Genre_ID, Name
Title_GenresPK FK Title_ID, Genre_ID
Watch_HistoryPK Watch_ID, FK Profile_ID, Episode_ID, Watbed_At, Progress_Sec

4. Microsoft Access Inplementazioa

Erreferentzia-osotasuna aktibatuta dago erlazio guztietan:

  • Txertaketa ordena: Plans, Genres, Accounts -> Titles -> Subscriptions, Profiles -> Episodes -> Title_Genres -> Watch_History.
  • Ezabatze ordena: Watch_History -> Title_Genres, Episodes -> Profiles, Subscriptions -> Titles, Plans, Genres, Accounts.
