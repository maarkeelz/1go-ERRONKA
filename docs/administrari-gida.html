Windows Server 2019 - Administrari Gida

WindowsServer6Taldea zerbitzariaren konfigurazio ofiziala eta administrazio-gidalerroak.

Deskargatu .md Aurkibidea

1. Zerbitzariaren Datuak eta IsardVDI Hardwarea

  • Ekipoaren Izena: WindowsServer6Taldea (WORKGROUP)
  • Sistema Eragilea: Windows Server 2019 Standard (1809 GUI) eguneratua
  • IsardVDI Hardwarea: 6 vCPU, 16 GB RAM, Virtio disko busa, Vlan 70
  • MAC Helbidea: 52:54:00:1e:ab:f1
  • IPv4 Estatikoa: 192.168.70.2 / 24 (Atebidea: 192.168.70.254)
  • DNS Zerbitzariak: 8.8.8.8 (Nagusia), 6.6.6.6 (Alternatiboa)

2. Tokiko Erabiltzaileak eta Taldeak

EditoreaAdmin_123Erronka EditoreakFitxategiak editatzeko eta kudeatzeko erabiltzailea

3. Segurtasun Zuzentarau Lokalak (secpol.msc)

Pasahitz Gidalerroak

  • Gutxieneko luzera: 8 karaktere
  • Konplexutasuna: Gaituta
  • Historiala: 24 pasahitz gogoratu
  • Indarraldia: Gehieneko 90 egun, gutxieneko 1 egun

Kontua Blokeatzeko Gidalerroak

  • Blokeo-muga: 10 saiakera oker
  • Blokeoaren iraupena: 15 minutu
  • Kontagailua berrezartzeko epea: 10 minutu

4. NTFS Baimenak eta Karpeta Egitura

Hasierako proba karpetan (C:\Erronka Proba) eta RAID web karpetan:

  • Erronka Editoreak: Modificar baimena
  • Erronka Irakurleak: Lectura y ejecucion baimena
  • Administradores eta CREATOR OWNER: Control total

5. IIS Web Zerbitzaria eta Windows Defender Firewall

IIS zerbitzaria HTTP 80 atakan konfiguratuta dago 192.168.70.2 helbidean. Sarrerako araua PowerShell bidez:

New-NetFirewallRule -Name "IIS-HTTP-Inbound" -DisplayName "IIS Web Zerbitzaria (Port 80 HTTP)" -Enabled True -Direction Inbound -Protocol TCP -LocalPort 80 -Action Allow

6. Windows Server Backup

Eguneroko babeskopia automatikoak programatuta kanpoko disko batera (sistema-egoera eta web karpeta). Ezabatze-proba baten ondoren fitxategia segundotan leheneratu da.
