1. 1. eta 2. OSI Geruzak Muntaian

1. Geruza: Fisikoa

  • Bitartekoa: UTP Cat 6 kableatua (4 pare bihurritu).
  • Konektoreak: RJ-45 arrak eta patch-paneleko keystone emeak.
  • Funtzioa: Bit-sekuentziak seinale elektriko bihurtzea.

2. Geruza: Datu-Lotura

  • Helbideratzea: MAC helbide fisikoak (zerbitzaria: 52:54:00:1e:ab:f1).
  • Hardwarea: 2. geruzako switch-a (talka-domeinuak banatzeko).
  • Trama: Ethernet II trama eta FCS kontrola.

3. Admin_123 ASCII eta CRC-6-GSM Kalkulua

Probako pasahitza (Admin_123) 72 biteko katea bihurtuta:

01000001 01100100 01101101 01101001 01101110 01011111 00110001 00110010 00110011

Polinomio sortzailea: G(x) = x^6 + x^5 + x^3 + x^2 + x + 1 (Bitarrean: 1101111)

Modulo-2 zatiketa egin ondoren lortutako hondarra: 011010 (Hamartarra: 26, Hex: 0x1A).

4. Seinale Modulazioak eta Konektibitate Probak

  • ASK(2): Anplitudearen modulazioa ('1' altua, '0' baxua).
  • FSK(2): Maiztasunaren modulazioa ('1' maiztasun handia, '0' baxua).
  • PSK(2): Fasearen aldaketa 180 graduetan.
  • Manchester: Tentsio-trantsizioa bit bakoitzaren erdian.
