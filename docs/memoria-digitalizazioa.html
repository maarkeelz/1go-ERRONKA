2. IT vs OT Konparaketa

EzaugarriaIT (Informazio Teknologiak)OT (Teknologia Operatiboa)
FuntzioaDatuak, transakzioak eta kudeaketaMundu fisikoa eta makinak kontrolatzea
GailuakZerbitzariak, ordenagailuak, datu-baseakPLCak, robotak, sentsoreak, SCADA
LehentasunaKonfidentzialtasuna (C > I > A)Eskuragarritasuna eta Segurtasuna (A > I > C)
LatentziaSegundotan onargarriaDenbora erreal zorrotza (mikrosegundotan)

3. Teknologia Gaitzaile Digitalak (THD) eta GitHub Projects

  • Cloud Computing: Baliabideak eskariaren arabera eskalatzea (IaaS, PaaS, SaaS).
  • IoT: Sentsore bidezko datu-bilketa automatikoa.
  • Big Data: Erabiltzaileen ohiturak aztertzeko analitika.
  • Adimen Artifiziala: Gomendio-sistemak.
  • Zibersegurtasuna: Datuen zifraketa eta sarbide-kontrola.
  • GitHub Projects: Kanban taula lau zutabetan (To Do, In Progress, In Review, Done).
