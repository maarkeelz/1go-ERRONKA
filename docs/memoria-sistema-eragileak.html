Sistema Eragileak eta Zerbitzaria - Memoria Teknikoa

Sistema Eragileak Ezartzea moduluaren memoria teknikoa eta azpiegitura.

Deskargatu .md Aurkibidea

1. IsardVDI eta WindowsServer6Taldea

  • Plataforma: IsardVDI birtualizazioa
  • Baliabideak: 6 vCPU, 16 GB RAM, Virtio diskoa, Vlan 70
  • Hostname: WindowsServer6Taldea (WORKGROUP)
  • IP Estatikoa: 192.168.70.2 / 24 (Atebidea: 192.168.70.254)
  • DNS: 8.8.8.8 / 6.6.6.6
  • Sistema: Windows Server 2019 GUI eguneraketekin

2. Segurtasun Zuzentarauak eta Erabiltzaileak

Tokiko Erabiltzaileak

  • Editorea (Erronka Editoreak taldea)
  • Irakurlea (Erronka Irakurleak taldea)
  • Pasahitza bi erabiltzaileentzat: Admin_123

Politikak (secpol.msc)

  • Gutxieneko luzera: 8 karaktere
  • Konplexutasuna: Gaituta
  • Historiala: 24 pasahitz
  • Blokeoa: 10 saiakera oker (15 minutu)

3. Disko-Kudeaketa, RAID eta IIS

  • RAID 1 (Ispilua): 2 disko dinamiko erabiliz (% 50 erabilgarri). Webgunea bertan gordetzen da.
  • RAID 5 (Paritatea): 3 disko dinamiko (% 66 erabilgarri).
  • IIS Web Zerbitzaria: HTTP 80 atakan, 192.168.70.2 helbidean.

Firewall sarrerako araua gaitzeko PowerShell komandoa:

New-NetFirewallRule -Name "IIS-HTTP-Inbound" -DisplayName "IIS Web Zerbitzaria (Port 80 HTTP)" -Enabled True -Direction Inbound -Protocol TCP -LocalPort 80 -Action Allow

4. Babeskopiak eta Berreskuratze Prozedura

Copias de seguridad de Windows Server bidez eguneroko babeskopiak programatu dira. index.html ezabaketaren proban, fitxategia segundotan leheneratu da datu-galerarik gabe.
