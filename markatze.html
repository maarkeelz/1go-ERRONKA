Markatze Lengoaiak eta Webgunearen Egitura

SISA 1eko 1. erronkaren webgune estatikoaren garapena: karpetaren antolaketa, HTML5 egitura semantikoa, CSS3 estiloak eta GitHub Pages bidezko dokumentazioa.

1. Karpetaren Egitura eta Fitxategi Nagusiak

Proiektu osoa biltegi bakar batean antolatuta dago, bide erlatiboak erabiliz eramangarritasuna bermatzeko:

Fitxategia / KarpetaMotaDeskribapena
index.htmlHTML5Hasierako orria, proiektuaren aurkezpena eta zerbitzariaren fitxa teknikoa.
sareak.htmlHTML5Sare azpiegitura fisikoa, OSI 1-2, T568B, ASCII, CRC-6 eta modulazioak.

2. Web Orrien Garapena eta Edukiak

Hasiera (index.html)

Erronkaren helburu nagusiak, modulu bakoitzerako sarbide-txartelak eta WindowsServer6Taldea makinaren ezaugarriak.

Sareak (sareak.html)

UTP Cat 6 kableatua, T568B estandarra, Admin_121 pasahitzaren 72 bitak, CRC-6-GSM kalkulua eta seinale digitalak.

Datu-baseak (datu-baseak.html)

Streaming plataformaren ER diagramak, 3NF normalizazioa, Plan_Titles sarbidea eta Access-eko txertatze-ordena.

Sistema Eragileak (sistema-eragileak.html)

Windows Server 2025, IP estatikoa (192.168.70.2), secpol.msc, NTFS baimenak, RAID 1/5 eta Windows Backup.

Digitalizazioa (digitalizazioa.html)

Digitalizazio-mailak, IT vs OT konparaketa taula, Industria 4.0ko THDak eta GitHub Projects jarraipena.

3. HTML5 Semantika eta CSS3 Diseinu Arauak

HTML5 Egitura Semantikoa

  • header: Goiburukoa logoarekin eta taldearen izenarekin.
  • nav: Orri guztietan berdina den nabigazio-menua.
  • main eta section: Eduki nagusiaren banaketa logikoa.
  • footer: Oin-oharra zerbitzariaren eta moduluen estekekin.

CSS3 Estiloak (UD-02)

  • Kutxa-eredua: box-sizing: border-box tamaina zehatzetarako.
  • Tipografia: Times New Roman estilo soila eta Courier New kodearentzat.
  • Koloreak: Ikatz-gris iluna (#2b2b2b), gorria (#c0392b) eta grisa (#eeeeee).
  • Responsive: Flexbox txartelak eta 768px-ko media query-a mugikorrerako.

4. Dokumentazio Teknikoa eta GitHub Pages

Proiektuaren dokumentazioa Markdown formatuan garatu da doc/ karpetan eta GitHub Pages bidez hedatu da:

  • Memoria teknikoak: Sareak.md, Datu Baseak.md, Digitalizazioa.md, Sistema Eragileak.md eta Markatze.md fitxategiak.
  • Access fitxategia: doc/files/Streaming.accdb datu-base erreala gordetzen da erlazioak egiaztatzeko.
