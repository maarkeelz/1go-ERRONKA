GitHub-en egindako planifikazioa

Erronkaren lana antolatzeko, GitHub Projects erabili dugu. Tresna horren bidez, zereginak banatu, arduradunak esleitu, entrega-epeak zehaztu eta proiektuaren aurrerapena kontrolatu dugu.

1. Proiektuaren biltegia

Proiektuaren fitxategiak 1go-ERRONKA biltegian gorde ditugu. Bertan, webgunearen HTML orriak, CSS estiloak, irudiak eta dokumentazioa antolatu ditugu.

Egindako aldaketak commits bidez erregistratu ditugu, lanaren bilakaera ikusteko.

2. Zereginen antolaketa eta etiketak

Egin beharreko jarduerak issues bidez antolatu ditugu. Zeregin bakoitzean egin beharreko lana zehaztu dugu, eta arduradunak, etiketak eta dagokion mugarria esleitu ditugu.

Horrela, taldeko kide bakoitzak bere zereginak eta entrega-epeak identifika ditzake.

Arloen araberako etiketak

  • DATU BASEAK: datu-baseen diseinua eta inplementazioa.
  • DIGITALIZAZIOA: digitalizazioa eta teknologia digitalak.
  • DOKUMENTAZIOA: azalpenak eta dokumentuak prestatzea.
  • MARKATZEKO LENGOAIAK: webgunearen egitura, edukia eta estiloak.
  • SAREAK: sare-konfigurazioa, kableak eta seinaleen kodifikazioa.
  • SISTEMA ERAGILEAK: Windows Server, diskoak, baimenak eta babeskopiak.

3. Epeak eta mugarriak

Milestones edo mugarriak erabili ditugu lana egunetan banatzeko. Lehen asteko astelehenetik bigarren asteko ostegunera arteko bederatzi mugarri sortu ditugu.

Eguneko helburuak

Mugarri bakoitzak entrega-data eta zeregin multzo bat ditu. Horrela, egun bakoitzean amaitu beharreko lanak zehaztu ditugu.

Aurrerapenaren kontrola

Mugarri bakoitzean amaitutako eta egiteko dauden zereginak eta aurrerapenaren ehunekoa ikus daitezke. Horrek atzeratutako lanak identifikatzen laguntzen digu.

4. Kanban taula eta Gantt diagrama

Planifikazioa bi ikuspegitan antolatu dugu, zereginen egoera eta egutegia kontsultatzeko.

Kanban taula

Zereginak egoeraren arabera antolatzeko eta lanaren jarraipena egiteko erabili dugu.

Gantt diagrama

Zereginen hasiera- eta amaiera-datak, iraupena eta denboran duten banaketa ikusteko erabili dugu. Aldi berean egiten diren lanak ere identifika ditzakegu.

Informazioaren Digitalizazioa

1. Informazioaren Digitalizazioaren Kontzeptua

Digitalizazioa da errealitate fisikoko prozesuak, zerbitzuak, informazioa eta negozio-ereduak teknologia digitalak erabiliz eraldatzea. Helburua lanak azkarrago, eraginkorrago, seguruago eta konektatuago egitea da.

Askotan paper bateko dokumentu bat eskaneatzea besterik ez dela pentsatzen dugu, baina digitalizazioa harago doa: ez du bakarrik informazioa digitu batean gordetzen, baizik eta datuak erabiliz prozesuak automatizatzea, erabakiak hobetzea eta bezeroei edo erabiltzaileei zerbitzu berriak eskaintzea lortzen du.

Adibidez, denda bat digitalizatzen bada, online saldu dezake, bezeroen datuak kudeatu, ordainketak automatizatu eta salmenten datuak aztertu erabaki hobeak hartzeko.

2. IT eta OT Teknologiak

IT (Informazioaren Teknologiak) datuak prozesatzeko, informazioa kudeatzeko eta erabakiak hartzeko erabiltzen diren teknologiak dira. Adibidez: datu-baseak, aplikazioak, sareak, softwarea eta hodeiko zerbitzuak.

OT (Operazio edo Eragiketa Teknologiak) prozesu fisikoak kontrolatzeko eta automatizatzeko erabiltzen dira. Adibidez: sentsoreak, PLCak, robotak, SCADA sistemak, kamerak eta termostatoak.

IT eta OT elkarrekin lan egiten dute: OTk datuak biltzen ditu makinetatik, eta ITk datu horiek aztertu, gorde eta erabakiak hartzeko erabiltzen ditu. Horri esker, mantentze prediktiboa, ekoizpenaren kontrola eta eraginkortasun handiagoa lortzen dira.

3. Teknologia Gaitzaile Digitalak (THD)

Teknologia Gaitzaile Digitalak (THD) digitalizazioa ahalbidetzen duten teknologiak dira. Gaitasun berriak, automatizazioa, berrikuntza eta negozio-eredu berriak sortzen laguntzen dute.

THD nagusien artean daude:

  • IoT (Gauzen Internet): gailu fisikoak Internetera konektatzea eta datuak denbora errealean biltzea.
  • Adimen Artifiziala (AA/IA): makinei ikasteko eta erabakiak hartzeko aukera ematen dieten teknikak.
  • Big Data: datu-bolumen handiak biltzea, gordetzea eta aztertzea.
  • Cloud computing: datuak eta aplikazioak Internet bidez gordetzea eta prozesatzea.
  • Zibersegurtasuna: sistemak, sareak eta datuak eraso digitalen aurka babestea.
  • Errealitate areagotua (AR) eta birtuala (VR): esperientzia digital murgiltzaileak sortzea.
  • Blockchain: transakzioen erregistro deszentralizatu eta segurua.
  • 5G: konektibitate azkarragoa eta fidagarriagoa.
  • Robotika, 3D inprimaketa eta biometria: automatizazioa, fabrikazio digitala eta identifikazio segurua.
  • Robotika kolaboratzailea (cobots): gizakiekin batera lan egiten duten robotak dira; errepikakorrak edo arriskutsuak diren atazak automatizatzen dituzte fabriketan, biltegietan eta osasun-zerbitzuetan.
  • Digital twins (biki digitalak): objektu, makina edo prozesu fisiko baten eredu digitala da, datuak erabiliz denbora errealean simulatzeko, kontrolatzeko eta hobetzeko.

THDek ezaugarri hauek dituzte: moldakortasuna, automatizazioa, interkonexioa, analitika aurreratua, segurtasuna, eskalagarritasuna, pertsonalizazioa, aurreztea eta berrikuntza.

4. Cloud Computing (hodeiko konputazioa)

Cloud computing datuak, aplikazioak eta zerbitzuak Internet bidez gordetzeko eta erabiltzeko teknologia da. Erabiltzaileak ez du beti bere hardware fisikoaren mende egon behar; datuak hodeian gordetzen dira eta edozein gailutik atzitu daitezke.

Hodei-konputazioan (cloud computing) hiru hodei mota nagusi daude: publikoa, pribatua eta hibridoa. Denek datuak eta aplikazioak Internet edo sare pribatu baten bidez gordetzeko eta prozesatzeko aukera ematen dute, baina nork kudeatzen duen eta nork erabiltzen duen aldatzen da.
