Informazioaren Digitalizazioa eta IT / OT

Enpresen eraldaketa digitala, Informazioaren Teknologien (IT) eta Teknologia Operatiboen (OT) arteko zubiak, Industria 4.0ko gaitzaile digitalak (THD) eta GitHub Projects kudeaketa.

1. Informazioaren Digitalizazioaren Kontzeptua

1. Digitization

Datu fisikoak bit bihurtzea (adib. paperezko kontratuak PDF formatura pasatzea).

2. Digitalization

Prozesuak automatizatzea (adib. harpidetza bat online kontratatu eta zerbitzua berehala aktibatzea).

3. Digital Transformation

Negozio-eredu osoa berritzea (adib. bideoklub fisiko batetik streaming plataforma globalera igarotzea).

2. IT (Informazio Teknologiak) vs OT (Teknologia Operatiboa)

IT (Information Technology)

  • Helburua: Enpresako datuak eta kudeaketa-sistemak administratzea.
  • Lehentasuna: Konfidentzialtasuna (C > I > A).
  • Gailuak: Zerbitzariak, datu-baseak, sare lokalak eta PCak.

OT (Operational Technology)

  • Helburua: Mundu fisikoa eta prozesu industrialak kontrolatzea.
  • Lehentasuna: Eskuragarritasuna eta Segurtasun Fisikoa (A > I > C).
  • Gailuak: PLCak, robotak, sentsoreak eta SCADA sistemak.

3. Teknologia Gaitzaile Digitalak (THD - Industria 4.0)

Cloud Computing

Konputazio-baliabideak (IaaS, PaaS, SaaS) eskariaren arabera eskalatzeko balio du.

IoT (Gauzen Internet)

Sentsoreak konektatu datu-zentroetako tenperatura eta kontsumoa neurtzeko.

Big Data eta Analitika

Erabiltzaileen joerak aztertu eta streaming edukiaren katalogoa optimizatzeko.

Adimen Artifiziala (AA)

Gomendio-motorrak (Machine Learning) eta bezeroentzako laguntzaile automatikoak.

Zibersegurtasuna

Datuen zifraketa, autentifikazio segurua eta datuen babesa (RGPD/LOPD).

Green IT

Zerbitzarien energia-kontsumoa murriztea eta biltegiratze eraginkorra sustatzea.

4. Proiektuaren Kudeaketa: GitHub Projects

Lana Kanban metodologiaren bidez antolatu dugu lau zutabetan:

  • To Do: Egiteke dauden ataza guztiak (Kableatua, E-R diseinua, RAID prestaketa).
  • In Progress: Taldekideak unean garatzen ari diren lanak.
  • In Review: Egindako lanak taldean eta irakasleekin berrikusteko unea.
  • Done: Erabat amaitu eta ebidentziekin dokumentatutako atazak.
